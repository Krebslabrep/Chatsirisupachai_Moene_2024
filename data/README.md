# Data
This folder contains `.rds` files used in and generated from the analyses. These files were either retrieved from databases (e.g., lists of genes for mouse and _Drosophila_) or generated from publicly available sequencing data (e.g., Pol II ChIP-seq counts at each promoter). For more information on how these data files were prepared, please see the scripts in the folder `scripts/00_data_prep`. Note that we did not upload BAM files from the sequencing data; instead, we referenced these BAM files through Qinput files, which can be found in the folder `data/Qinput_files`. In the analysis scripts located in [scripts/](/scripts/), we have cited the original publications from which the BAM files were obtained.

This folder also contains `.rds` output files generated by the analyses.

## subfolders
* DM: Data files related to _Drosophila_. This folder includes output from analyses in the `amplicon_SMF`, `genome_wide_SMF`, and `PRO_seq` folders.
* MM: Data files related to mouse. This folder includes output from analyses in the `amplicon_SMF`, `bait_capture_SMF`, and `PRO_seq` folders.
* Modelling: Data files for modelling of Pol II turnover and transcription initiation. This folder includes output from analyses in the `output` folder.
* Qinput_files: Qinput files used to reference BAM files when using the `QuasR` R package for analysis.
